# Scenario 1 — Create EC2 Instance Using Terraform

## Task 1: Configure the AWS Provider

### Lab Overview

The Cloud Operations team requires a Terraform configuration that can communicate with AWS. In this task, you will create a Terraform configuration file and configure the AWS provider.

### Assessment Objectives

1. Create a Terraform configuration file named **main.tf**.
2. Configure the AWS provider.
3. Set the AWS region to **us-east-1**.
4. Save the configuration file in the working directory.

### Evaluation Criteria

- The **main.tf** file must be created successfully.
- The AWS provider block must be present.
- The AWS region must be configured correctly.
- Validation must be Successful.

---

## Task 2: Define an EC2 Instance Resource

### Lab Overview

The Cloud Operations team requires an Amazon EC2 instance to be provisioned using Infrastructure as Code. In this task, you will define an EC2 instance resource within the Terraform configuration.

### Assessment Objectives

1. Define an **aws_instance** resource.
2. Configure a valid Amazon Machine Image (AMI).
3. Configure the instance type as **t2.micro**.
4. Assign a resource name to the EC2 instance.

### Evaluation Criteria

- The EC2 resource definition must be present.
- A valid AMI must be specified.
- The instance type must be configured as **t2.micro**.
- Validation must be Successful.

---

## Task 3: Initialize the Terraform Working Directory

### Lab Overview

Before infrastructure can be provisioned, Terraform must initialize the working directory and download the required provider plugins.

### Assessment Objectives

1. Navigate to the Terraform project directory.
2. Initialize the Terraform working directory.
3. Download the required AWS provider plugins.

### Evaluation Criteria

- Terraform initialization must complete successfully.
- Provider plugins must be downloaded.
- Terraform must be ready for deployment.
- Validation must be Successful.

---

## Task 4: Validate the Terraform Configuration

### Lab Overview

The Cloud Operations team requires Terraform configurations to be validated before deployment to ensure there are no syntax or configuration errors.

### Assessment Objectives

1. Validate the Terraform configuration.
2. Confirm that no configuration errors exist.
3. Ensure the configuration is ready for deployment.

### Evaluation Criteria

- Terraform validation must complete successfully.
- No configuration errors should be reported.
- The configuration must be deployment-ready.
- Validation must be Successful.

---

## Task 5: Deploy the EC2 Instance

### Lab Overview

The Cloud Operations team requires the infrastructure to be deployed using Terraform. In this task, you will provision the EC2 instance defined in the Terraform configuration.

### Assessment Objectives

1. Review the Terraform execution plan.
2. Deploy the infrastructure using Terraform.
3. Create the EC2 instance in AWS.

### Evaluation Criteria

- The Terraform plan must be generated successfully.
- The Terraform deployment must complete successfully.
- The EC2 instance must be created in AWS.
- Validation must be Successful.

---

## Task 6: Verify the Provisioned Infrastructure

### Lab Overview

After deployment, the Cloud Operations team requires verification that the EC2 instance has been successfully provisioned and is being managed by Terraform.

### Assessment Objectives

1. Verify the EC2 instance exists.
2. Confirm the instance is in a running state.
3. Verify that the resource is tracked in the Terraform state.

### Evaluation Criteria

- The EC2 instance must exist in AWS.
- The instance must be running.
- Terraform state must contain the EC2 resource.
- Validation must be Successful.

### You have successfully completed the Scenario.
