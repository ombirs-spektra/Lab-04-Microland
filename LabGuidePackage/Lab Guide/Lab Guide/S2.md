# Scenario 12 — Safely Destroy Infrastructure

## Task 1: Review Terraform State

### Lab Overview

Before infrastructure is removed, the Cloud Operations team requires verification of the resources currently managed by Terraform.

### Assessment Objectives

1. Review the Terraform state.
2. Identify the resources managed by Terraform.
3. Confirm the EC2 instance is present in the state file.

### Evaluation Criteria

- Terraform state must be accessible.
- Managed resources must be visible.
- The EC2 instance must be present in the state.
- Validation must be Successful.

---

## Task 2: Review the Infrastructure Destruction Plan

### Lab Overview

The Cloud Operations team requires administrators to review pending changes before removing cloud resources. In this task, you will generate and review a destruction plan.

### Assessment Objectives

1. Generate a Terraform destruction plan.
2. Review the resources scheduled for removal.
3. Confirm the EC2 instance is included in the plan.

### Evaluation Criteria

- The destruction plan must be generated successfully.
- Resources scheduled for removal must be displayed.
- The EC2 instance must be included in the plan.
- Validation must be Successful.

---

## Task 3: Destroy the Terraform-Managed Infrastructure

### Lab Overview

To prevent unnecessary cloud costs and maintain a clean environment, the Cloud Operations team requires unused resources to be removed safely.

### Assessment Objectives

1. Destroy all Terraform-managed resources.
2. Remove the EC2 instance from AWS.
3. Complete the infrastructure removal process successfully.

### Evaluation Criteria

- Terraform destruction must complete successfully.
- The EC2 instance must be removed.
- No Terraform-managed infrastructure should remain.
- Validation must be Successful.

---

## Task 4: Verify Infrastructure Cleanup

### Lab Overview

After the infrastructure has been destroyed, the Cloud Operations team requires verification that all resources have been removed and Terraform state has been cleaned up appropriately.

### Assessment Objectives

1. Verify that the EC2 instance no longer exists.
2. Confirm that Terraform no longer manages any resources.
3. Review the Terraform state after destruction.

### Evaluation Criteria

- The EC2 instance must not exist in AWS.
- Terraform state must not contain managed resources.
- Infrastructure cleanup must be verified successfully.
- Validation must be Successful.

### You have successfully completed the Scenario.
